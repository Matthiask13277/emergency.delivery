# Emergency Delivery V164 – Standalone

Diese Version verwendet eine eingebettete PostgreSQL-kompatible lokale Datenbank (PGlite) und benötigt für den normalen Betrieb kein Docker, kein PostgreSQL und kein Node.js auf dem Ziel-PC.

Windows-Build: `INSTALLATION-WINDOWS.bat`
Installer-Ausgabe: `desktop\dist\Emergency-Delivery-Setup-1.64.0.exe`

Beim ersten Start wird die Datenbank automatisch im Windows-App-Datenordner angelegt und mit den Demo-Benutzern initialisiert.
